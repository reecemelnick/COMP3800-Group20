CSV format requirements:

The formatting of the CSV file has strict requirements which must be followed for the data to be appended to the database.

  • Columns names MUST match those in the example CSV file
  • All columns in the example CSV file must be present
  • Date Of Birth must be in the format MM/DD/YYYY
  • Gender Assigned At Birth must be either Male OR Female
  • Recall Frequency must be "3 Months", "6 Months" or "Yearly"
  • Date of Last visit must be in the format "MM/DD/YYYY HH:MM" (hour must be in 24-hour format)

Please refer to the createDubaiCleanTable.sql file or documentation to see the character limits for certain fields
